# x1-fd-tools

X1turbo / LSX-Dodgers用の、フロッピーディスクとD88ディスクイメージを相互変換するツールです。

| コマンド | 機能 |
|---|---|
| `fd2img.com` | FDを読み取り、D88ファイルへ保存する。ディスク情報の表示にも対応 |
| `img2fd.com` | D88ファイルの内容をFDへ書き戻す |

Copyright (c) 2026 X1turboAgency

## 動作環境

- X1turboシリーズとLSX-Dodgers。
- 対象メディアに対応する物理フロッピードライブ (2D/2DD/2HD)
- D88ファイルを読み書きできる、十分な空き容量を持つドライブ。(HDDを想定してます)

X1は対象外です。<br>
DMAを使って読書きしているのと、作業用の広い領域はHDD以外にはほぼなく、<br>
LSX-DodgersではEMM領域でも広く確保できないためです。<br>
起動時に機種を判定し、X1turbo以外では処理を終了します。<br>
一般のCP/MやMSX-DOS上での実行には対応しません。<br>
表示・エラーメッセージは、低解像度の画面でも読めるよう英語（ASCII）です。<br>
2DD・2HDの使用には、対応ドライブと本体・ドライブ側の適切な設定が必要です。<br>
特に2DDはディップスイッチの切り替えが必要です。

## 使い方

```text
fd2img fdN-media output.d88 [-tr start-end]
fd2img fdN-media -i [-tr start-end]
img2fd fdN-media input.d88 [-tr start-end]
```

`fdN-media` は必須です。例えば `fd0-2d` は「物理FDD 0を2Dモードで扱う」指定です。<br>
物理FDD番号と、ファイル名の `H:` などのドライブ指定は独立しています。

| 指定 | 内容 |
|---|---|
| `N` | 物理FDD番号。`0`～`3` |
| `media` | メディア。`2d`、`2dd`、`2hd` |
| `output.d88` | 出力先。通常の `fd2img` では必須。ドライブ指定は h: を付けてください |
| `input.d88` | 入力元。`img2fd` では必須 |
| `-tr start-end` | 両端を含む論理トラック範囲。10進数 |
| `-tr number` | 単一の論理トラック |
| `-i` | `fd2img` 専用。ディスク情報のみを表示。出力ファイル名は指定しない |
| `-h` | 使用方法を表示 |

大文字・小文字は区別しません。FD・メディア指定を先、ファイル名を後に指定します。<br>
メディアの自動判別は行いません。必須引数が不足している場合は使用方法を表示して終了します。<br>

トラック指定を省略すると、指定メディアの全範囲を処理します。<br>

| メディア | 論理トラック範囲 |
|---|---|
| 2D | 0～79 |
| 2DD | 0～159 |
| 2HD | 0～153 |

論理トラック番号は「シリンダ番号×2＋サーフェス番号」です。<br>
範囲外の番号、開始番号が終了番号を超える指定はエラーになります。<br>
部分ダンプでもD88内のトラック番号を詰め直しません。<br>

ファイル名はASCIIの8.3形式です。ドライブ指定を省略するとカレントドライブ、<br>
拡張子を省略すると `.D88` を使用します。パスやワイルドカードは指定できません。<br>
`.$$$` は一時ファイル用の予約拡張子です。<br>

### FDをD88にイメージ化する

```text
fd2img fd0-2d h:test.d88
fd2img fd1-2dd j:part.d88 -tr 10-15
```

開始前に、対象FD・メディア・トラック範囲・出力名を表示し、続行を確認します。<br>
`y` / `Y` で続行、`n` / `N` で中止します。<br>

出力先と同じドライブに `TEST.$$$` のような一時ファイルを作成します。<br>
各トラックを追記し、最後にD88ヘッダとトラックテーブルを更新してから `TEST.D88` にリネームします。<br>
既存の完成ファイルや同名の一時ファイルは上書きしません。<br>

例えばカレントドライブがH:で `j:dump.d88` と指定すると、<br>
`J:DUMP.$$$` を作成し、完了後に `J:DUMP.D88` へリネームします。<br>
コマンドの格納先と、イメージファイルの入出力先は別々に指定できます。<br>

CRCなどの読み取りエラーは記録して後続トラックへ進み、処理終了後に一覧を表示します。<br>
取得できなかったトラックはD88の未収録トラックになります。<br>
ディスク未準備やFDC待ちのタイムアウト、出力ファイルのI/Oエラーでは処理を中断します。<br>
中断時は一時ファイルが残る場合があります。残った一時ファイルは完成したD88として扱わないでください。<br>

### ディスク情報だけを表示する

```text
fd2img fd0-2d -i
fd2img fd1-2dd -i -tr 10-15
```

セクタIDを読み取り、トラックごとに検出順のセクタ番号とバイト数を表示します。<br>
セクタ番号は2桁の16進数、バイト数は10進数です。<br>

```text
Read track: 0
 #01/512 #03/512 #05/512 #07/512 #09/512 #02/512 #04/512 #06/512 #08/512
```

最後に、同じセクタ構成が連続するトラック範囲、検出したシリンダ・サーフェス数、容量を集計します。<br>
容量はセクタIDから計算するデータ容量で、D88ファイルサイズやファイルシステムの空き容量ではありません。<br>
一部のトラックを指定した場合は、その範囲の容量を表示します。<br>
取得不能・サイズ不明のIDがある場合は、容量不明と取得できたID分の容量を表示します。<br>

このモードではD88ファイルを作成せず、セクタデータの読み取りも行いません。<br>
データ本体やデータCRCの正常性を検証するモードではありません。<br>

### D88イメージをFDに書き戻す

```text
img2fd fd0-2d h:test.d88
img2fd fd1-2dd j:part.d88 -tr 10-15
```

**指定範囲内の収録トラックをフォーマットし、FDの内容を上書きします。**<br>
書きこまれる際に消去されるためご注意ください。<br>
対象ドライブ・メディア・トラック範囲を確認してください。<br>

開始確認の後、入力D88のサイズ・メディア・選択範囲のトラック構造と記録容量を検査します。<br>
検査中は `Check track:` で進行を表示します。<br>
検査に成功してから、FDへの書き込み直前にもう一度確認します。<br>
2回目の確認までに中止した場合はFDへ書き込みません。<br>

未収録トラックはスキップし、FD上の該当トラックを変更しません。<br>
指定範囲がすべて未収録の場合はエラーです。<br>
入力D88は変更しません。書き込み途中で失敗した場合、既に書き込んだFDの内容は元に戻りません。<br>
書き込む際にトラックはフォーマットされるため、事前にフォーマットは不要です。<br>
2D/2DD, 2HDはメディア的に区別されるため対応するメディアを使用してください。<br>

## 対応形式と制限

- 通常のダンプ・書き戻しはMFM、セクタ長128・256・512・1024バイト、1トラック最大32セクタが対象です。
- 情報表示モードはIDのN=0～7をサイズ計算の対象とし、それ以外はサイズ不明と表示します。
- ダンプでは取得したCHRN、セクタ順、削除データマーク、読み取りエラー状態をD88へ記録します。
- 書き戻しは単一ディスクのD88が対象です。連結D88には対応しません。
- 書き戻しでは、正常なセクタ構造、重複のないID、トラック容量などを検査します。
  CRCエラーを記録したイメージや、特殊なCHRN・重複ID・FM記録などは書き戻し対象外です。
- D88に含まれない元のGAPや磁気記録タイミングは再現しません。
  プロテクトディスクの完全複製を保証するツールではありません。
- ディスク未準備やFDC・INDEX待ちの上限超過では、後続トラックへ進まず終了します。
  タイムアウトの実時間はCPUクロックや環境によって変わります。

## ソースとビルド

ソースは `develop/src/` に収録しています。<br>
コメントを含めCP932（SJIS系）・LFで保存しています。<br>
文字列定義の複数文字列はダブルクォーテーションで囲みます。<br>

| 主なソース | 内容 |
|---|---|
| `fd_d88_main.asm` | FD → D88のメイン処理 |
| `d88_fd_main.asm` | D88 → FDのメイン処理 |
| `cli.asm` / `confirm.asm` | 引数解析・開始確認 |
| `d88_input.asm` / `d88_output.asm` | D88ファイルの入出力 |
| `fd_capture.asm` / `fd_restore.asm` | FDの読み取り・書き戻し |
| `disk_info.asm` / `read_report.asm` | 情報表示・エラー一覧 |
| `iocs_fdd.asm` | FDC・DMAアクセス |
| `build_fd_d88.asm` / `build_d88_fd.asm` | 各COMのビルド入口 |

`develop/make.bat` を同梱する構成では、アセンブラにz80asを用意し、<br>
リポジトリのルートで次を実行すると、両COMを `release/` に出力できます。<br>

```text
make.bat
```

このスクリプトは作業用コピーでモジュール末尾のENDなどを調整し、元のソースを変更せずビルドします。
